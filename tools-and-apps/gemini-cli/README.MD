# Gemini CLI


## Installation

### Windows

Open PowerShell.

Install nodejs:
```winget install -e --id OpenJS.NodeJS```<br>

Reopen PowerShell.

Install gemini-cli:
```npm install -g @google/gemini-cli```<br>

Run gemini-cli:
```gemini```<br>

### VS Code
vs-code extension: Gemini CLI Companion

Run gemini-cli in vs-code terminal :
```gemini```

Check IDE status:
```
> /ide status
ℹ 🟢 Connected to IDE
```
*Close the terminal and open a new terminal if connection error.*
